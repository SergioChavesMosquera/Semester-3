## Temas del preparcial (confirmados)

### Sección 1: Lógica y Conjuntos
1. Tabla de verdad + razonamiento lógico informal para tautología: (p → (q → r)) → ((p → q) → (p → r))
2. V o F con demostración/contraejemplo:
   - a) Para todo conjunto A, A ⊆ 𝒫(𝒫(A))
   - b) Para todo conjunto A, 𝒫(A) ∈ 𝒫(𝒫(A))
3. Describir conjunto {6, 10, 14, 18, 22, ...} intensionalmente como {x ∈ ℕ : p(x)}

### Sección 2: Verdadero o Falso (con justificación)
1. Existe X tal que si X ∩ B = X ∩ C, entonces B = C
2. 𝒫(A ∪ B) ⊇ 𝒫(A) ∪ 𝒫(B)
3. (A ∪ B) \ A = B \ A
4. Si R y S son reflexivas sobre X, entonces R ∪ S también lo es

## Observaciones del estilo del profe (de las clases)
- Usa lápiz/tablero con apuntes manuscritos, muchos colores (resaltados amarillo, cyan, rosa)
- Las demostraciones son formales: "Sea x ∈ ... ⟹ ... ⟹ ... QED"
- Le gustan los diagramas de Venn para intuición
- Enfatiza diferencia entre ∈ (pertenece) y ⊆ (está contenido)
- Pide justificación en todo — igual que el profe de Cálculo
- Los ejercicios de V o F requieren demostración si es verdadero y contraejemplo si es falso
